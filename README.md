# N4V FOR WEBI

**Modern decision-making projects, built on SAP BusinessObjects.**

N4V FOR WEBI is a suite of extensions for **SAP BusinessObjects Web Intelligence**, published by [Need4Viz](https://www.need4viz.com/), a Paris-based **SAP Build Partner**. It adds interactive dashboards, maps, AI and HTML5 publishing directly on top of your existing Web Intelligence reports.

**No migration. No code.**

## What is N4V FOR WEBI?

A software suite that extends SAP BusinessObjects Web Intelligence (WebI) with advanced data visualization, cartography, artificial intelligence and web publishing, while keeping your existing BusinessObjects universes, security and reports.

## Three axes

| Axis | What it means |
|---|---|
| **Simplify** | Build richer WebI documents with guided extension panels instead of scripting. |
| **Enhance** | Add interactive charts, maps and natural-language AI on top of data already modelled in your universes. |
| **Facilitate** | Publish WebI content as responsive HTML5 and share it widely, without additional SAP front-end licences. |

## The four modules

| Module | Purpose |
|---|---|
| **N4V Widgets** | 60+ interactive chart types for Web Intelligence. |
| **N4V Maps** | Geographic information (GIS) and cartography inside WebI. |
| **N4V Publisher** | Export WebI documents to standalone responsive HTML5 dashboards. |
| **N4V Intelligence** | AI for WebI: natural-language questions, explanations and assisted analysis. |

## Why teams choose it

- **No migration**: your SAP BusinessObjects platform, universes and security stay in place.
- **No code**: configuration through extension panels.
- **Specialist**: built for Web Intelligence by an SAP Build Partner.
- **Investment-friendly**: extends what you already own instead of replacing it.
