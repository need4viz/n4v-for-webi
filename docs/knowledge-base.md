# Knowledge Base index – N4V FOR WEBI

This page lists the public Need4Viz Knowledge Base articles for N4V FOR WEBI (extensions for SAP BusinessObjects Web Intelligence), grouped by topic: installation and configuration, display issues, component settings, navigation, export, panels and dashboards. Each entry links to the full article (symptom, environment, resolution steps) on the Need4Viz support portal. The knowledge base is written in English.

- Knowledge Base: https://support.need4viz.com/kb/
- Product documentation (one page per widget): https://www.need4viz.com/dokuwiki/
- Release notes: https://www.need4viz.com/category/release-notes-n4v/
- Support portal: https://www.need4viz.com/support/

## Full-text summaries (symptom, cause, solution)

The articles are also summarized in Markdown, one file per category, so that the symptom and the resolution can be read directly in this repository:
