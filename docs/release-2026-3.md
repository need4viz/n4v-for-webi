# N4V FOR WEBI 2026.3 — Release notes

Release date: September 30, 2026 · Product: N4V FOR WEBI (N4V Widgets, N4V Maps, N4V Publisher, N4V Intelligence, N4V Dashboard Builder, N4V panels)

Release 2026.3 is a minor release: improvements and enhancements to existing components, plus a new AI module, N4V Insights.

## Highlights

- **N4V Insights (new, in N4V Intelligence):** AI analyzes every component of the dashboard, taking the applied filters into account. It writes a data-backed analysis (trends, breaks, gaps between indicators, points to watch), suggests questions, accepts free-text input, and can generate a PowerPoint presenting the insights with the related charts.
- **Enhanced N4V Dashboard Builder:** a 100% web application, introduced in release 2026.2, to build a dashboard with no code from N4V widgets calculated in Web Intelligence.
  - Designers: external source and publishing, collaborative saving on the server, complete interactive dashboard documentation.
  - Readers: sections, carousel tiles, PDF printing, multi-select N4V elements, pop-up charts, advanced data view.
- **Enhanced widgets:**
  - Timeline: selecting several points displays the variance; a pop-up computes aggregations (sum, min, max, avg…) on the chosen zoom window.
  - Table filter: filters can be placed above the table and are nested by default.
  - Liquid gauge: fully responsive, with custom SVG shapes.
  - Pivot table: cumulative sum as an on-the-fly aggregation, optionally on a separate row; variance between points on a row.
  - Hemi Gauge: fully responsive, switches to trellis mode with several dimension values.
  - Select Multi: checkbox list, search with multiple selection, summary line of the active selection with a counter.
- **Enhanced N4V panels:**
  - The Settings panel shows the name and N4V family of the selected component.
  - Copy / Paste / Paste style buttons copy all settings (or only the style) between N4V components.
  - A template library changes the look of N4V components in one click.
  - A new export sends the dataset as XLSX to a public or personal folder in the SAP BI CMS.
  - The Chart Recommender can show components as a list or by family.

## 2026 roadmap

Two major releases (new components, in June and December) and two minor releases (fixes, improvements and enhancements, in March and September), complemented by HotFixes as needed. Next: major release 2026.4, in December 2026.
